## 二、每日 1.5 小时怎么拆？（黄金模板）

在职每天只有 1.5 小时，**最忌讳"漫无目的看视频"**。建议按 **1 + 0.5** 拆：

```
┌─────────────────────────────────────────────┐
│  0:00-1:00  「输入+输出」 看知识点+默写（60min）│
│              → 配套 资料/ 对应章节               │
│              → 看完关闭资料，手画流程图/默写原理  │
│              → 这一环节决定记不记得住            │
├─────────────────────────────────────────────┤
│  1:00-1:30  「算法」每天 1 题（30min）🌟        │
│              → 大厂/外企硬门槛，必须每天坚持      │
│              → 按 算法/00 计划，专题推进          │
│              → 限时 Easy 15min / Medium 30min   │
└─────────────────────────────────────────────┘
```

> ⚠️ **铁律**：
> 1. 默写那部分不能省。光看不写，3 天后忘 70%。
> 2. **算法每天 30 分钟雷打不动**——断手感恢复很慢。
> 推荐用 **Anki**（间隔重复）把记不住的做成卡片，碎片时间刷。

> 📌 **算法专题进度**（每天 30min，对应 算法/00）：
> W1 数组双指针 → W2 链表栈队列 → W3 哈希字符串 → W4 二叉树 → W5 二分排序 → W6 滑动窗口前缀和 → W7 回溯 → W8 动态规划 → W9 DP+堆TopK → W10 图BFS/DFS → W11 **手撕设计题** → W12 大厂真题
