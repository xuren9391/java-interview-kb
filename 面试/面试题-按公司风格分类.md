# 面试题 - 按公司风格分类

> 不同公司面试风格差异很大，**用同一套准备应对所有公司是吃亏的**。
> 本文帮你按目标公司类型定向准备，提高命中率。
> 配套：`面试/复习计划与执行表.md`

---

## 一、四类公司面试风格总览

| 维度 | 互联网大厂 | 独角兽/中型 | 外企 | 国企/银行金融 |
|------|-----------|------------|------|--------------|
| **技术深度** | 极深（源码/原理） | 深（实战） | 中（规范） | 中（基础） |
| **系统设计** | 必考且难 | 常考 | 少 | 少 |
| **算法** | 必考（中等难度） | 偶尔 | 偶尔 | 少 |
| **项目深度** | 必挖（5Why） | 必挖 | 适中 | 适中 |
| **架构/选型** | 重点 | 重点 | 适中 | 适中 |
| **管理/软素质** | 专家/管理岗重点 | 偏实战 | 重视协作 | 重视稳定 |
| **英语** | 不要求 | 不要求 | **要求**（部分） | 不要求 |
| **稳定性/规范** | 中 | 中 | **极高** | **极高** |
| **轮数** | 4-6 轮 | 3-4 轮 | 3-5 轮 | 2-4 轮 |
| **决策快** | 快（周内） | 快 | 慢（流程长） | 慢（审批） |

## 二、互联网大厂（阿里/字节/腾讯/美团/京东/拼多多/百度）

### 风格特点
- **重底层原理**：HashMap 源码、AQS、G1、MVCC、Raft，要讲到"为什么这么设计"。
- **重系统设计**：开放题（设计朋友圈/抢红包/12306），考思维广度。
- **重算法**：一般 2-3 道中等题（数组/树/DP/图），LeetCode 中频。
- **重项目深度**：5Why 追问，挖到你答不出为止，看你的真实深度。
- **节奏快、强度高**：每轮 1 小时，连续多轮。

### 准备重点
- 🔴 **JVM + 并发**：必须源码级（G1 流程、AQS、锁升级）。
- 🔴 **MySQL + Redis**：原理级（MVCC、B+ 树、跳表、集群）。
- 🔴 **系统设计**：练 5-8 个经典题（白板画图）。
- 🔴 **算法**：刷 100-200 题（剑指 Offer + LeetCode 高频）。
- 🔴 **项目**：旗舰项目准备到能被追问 30 分钟。
- 🟡 **分布式**：CAP、一致性算法、分布式事务。

### 大厂典型问题示例
- "讲一下 G1 的 Mixed GC 流程？什么时候触发 Full GC？"（原理）
- "设计一个抢红包系统，10 万人同时抢 1 万个红包，怎么防超卖？金额怎么分？"（系统设计）
- "手写：LRU 缓存 / 限流器 / 生产消费者。"（算法+设计）
- "你做过最有挑战的事？技术决策的取舍？"（项目）
- "给你 10 倍流量，你的系统哪里先扛不住？"（架构思维）

### 大厂分级参考（薪资参考，按 2026 行情，具体看 offer）
- 一线大厂（阿里/字节/腾讯）：3-1 ~ 3-2 / 2-2 ~ 3-1 对应 8-10 年，年包 80-150w+。
- 二线（美团/京东/百度）：同档位略低 10-20%。
- 拼多多：现金高，强度极大。

## 三、独角兽/中型公司（小红书/B站/滴滴/快手/米哈游/SaaS 独角兽）

### 风格特点
- **重实战经验**：你能直接上手解决问题，比理论重要。
- **重项目落地**：做过类似业务（电商/社交/直播/游戏），能复用经验。
- **重技术广度**：一人多能，前后端/运维都懂加分。
- **系统设计适中**：不像大厂那么开放，偏业务场景。
- **算法要求低**：基础题或没有。
- **节奏快、文化强调 ownership**。

### 准备重点
- 🔴 **项目落地能力**：突出"我做过类似的、能快速上手"。
- 🔴 **Spring + 微服务**：主流栈，必须熟。
- 🔴 **MySQL + Redis**：实战调优能力。
- 🟡 **高并发场景**：他们业务复杂，会问秒杀/缓存/MQ。
- 🟡 **全栈意识**：懂点前端/运维/部署加分。

### 独角兽典型问题示例
- "你之前的系统 QPS 多少？怎么扛的？"
- "秒杀场景你怎么设计？"
- "给你一个新业务（描述他们的业务），你怎么做技术方案？"
- "你们团队的 CI/CD 怎么做的？"
- "你怎么看新技术选型？自研还是开源？"

## 四、外企（微软/亚马逊/Google/Oracle/Booking/SAP/Thoughtworks）

### 风格特点
- **重英语**：部分全英文面试（亚马逊 LP 行为面试、Google）。
- **重算法（亚马逊/Google）**：LeetCode 中等偏上，现场编码。
- **重设计模式与工程规范**：代码质量、SOLID、测试。
- **重行为面试（Leadership Principles）**：亚马逊 16 条 LP 必准备。
- **重系统设计（部分）**：Google/亚马逊有。
- **重稳定性**：不鼓励 996，重 work-life balance。
- **流程长**：HC（Hiring Committee）审批，几周起步。

### 准备重点
- 🔴 **算法**：刷题（外企算法是硬门槛）。
- 🔴 **英语**：自我介绍英文版 + 项目英文描述 + LP 故事英文。
- 🔴 **行为面试**：准备 8-10 个故事覆盖 LP（亚马逊）/文化价值观。
- 🟡 **系统设计**：英文讲清架构。
- 🟡 **代码规范**：命名、测试、设计模式。

### 亚马逊 Leadership Principles（16 条，必准备）
1. Customer Obsession 客户至上
2. Ownership 主人翁精神
3. Invent and Simplify 创新与简化
4. Are Right, A Lot 判断准确
5. Learn and Be Curious 学习与好奇
6. Hire and Develop the Best 招育人才
7. Insist on High Standards 坚持高标准
8. Think Big 着眼大局
9. Bias for Action 崇尚行动
10. Frugality 节俭
11. Earn Trust 赢得信任
12. Dive Deep 深入细节
13. Have Backbone; Disagree and Commit 敢于反对并承诺
14. Deliver Results 交付结果
15. Strive to be Earth's Best Employer 争做最佳雇主
16. Success and Scale Bring Broad Responsibility 成功与规模带来责任

每个 LP 准备 1-2 个故事（STAR 格式），面试官会问 "Tell me about a time when..."

### 外企典型问题示例
- "Tell me about yourself."（英文自我介绍）
- "Tell me about a time you disagreed with your manager."（LP 故事）
- "Design Twitter / Design a URL shortener."（系统设计，英文）
- 算法：反转链表变种 / 滑动窗口 / DP。
- "How do you ensure code quality?"（工程规范）

## 五、国企/银行金融（四大行/股份制银行/券商/央企科技公司）

### 风格特点
- **重基础**：Java 基础、并发、JVM、数据库（八股为主，不深挖源码）。
- **重稳定性/规范**：编码规范、测试、文档、流程。
- **重数据一致性/事务**：金融场景对一致性要求极高。
- **不考/很少考系统设计和算法**。
- **重视合规/安全**：等保、数据安全。
- **流程繁琐**：笔试 + 多轮 + 背调 + 政审（部分）。
- **薪资稳定但上限低**：base 中等、福利好、稳定。

### 准备重点
- 🔴 **Java 基础八股**：集合、并发、JVM（基础题，不难但广）。
- 🔴 **数据库**：事务、锁、索引（一致性是重点）。
- 🔴 **分布式事务/一致性**：金融场景必问。
- 🟡 **消息队列**：可靠性、幂等。
- 🟡 **设计模式**：23 种里的高频。
- 🟢 **算法**：基础题（数组/字符串），不卷。

### 国企/银行典型问题示例
- "HashMap 原理？put 流程？"
- "synchronized 和 Lock 区别？"
- "MySQL 事务隔离级别？RR 怎么防幻读？"
- "分布式事务怎么保证？TCC 和 Seata 区别？"
- "幂等怎么实现？转账场景怎么保证不重复扣款？"
- "你怎么保证代码质量？"（规范、测试、Code Review）

### 银行金融特别关注
- **金额计算**：用 BigDecimal / 分（long），绝不用 double。
- **强一致性**：金融账户必须强一致，用 TCC / 2PC。
- **审计留痕**：所有操作可追溯。
- **对账**：日终对账是标配。
- **风控**：反欺诈、限额。

## 六、定向准备策略（按你投的公司调整）

### 投大厂时
1. 算法每天 1-2 题（持续）。
2. 系统设计白板练 5 个题。
3. 项目准备到能扛 30 分钟追问。
4. 八股查漏补缺到源码级。

### 投独角兽时
1. 重点讲项目落地经验。
2. 主流技术栈（Spring Cloud Alibaba）讲透。
3. 业务场景题（秒杀、缓存、MQ）多准备。
4. 表现"能扛活、上手快"。

### 投外企时
1. **英语**（每天练 30 分钟口语/写英文简历）。
2. **算法**（刷题是硬门槛）。
3. **行为面试故事**（LP / 文化价值观）。
4. 系统设计英文表达。

### 投国企/银行时
1. Java 基础八股（广而稳）。
2. 数据库一致性/事务（重点）。
3. 设计模式 + 编码规范。
4. 强调稳定性、合规意识。

## 七、面试流程对照

| 公司类型 | 典型流程 |
|---------|---------|
| 大厂 | 简历筛选 → 1-3 轮技术（含算法+系统设计） → 交叉面 → HR 面 → Offer（1-2 周） |
| 独角兽 | 投递 → 2-3 轮技术 → HR → Offer（1 周内） |
| 外企 | 投递 → OA 在线测评 → 1-2 轮技术 → 行为面 → HC 审批 → Offer（3-6 周） |
| 国企/银行 | 投递/网申 → 笔试 → 1-2 轮面试 → 背调/政审 → 审批 → Offer（1-3 月） |

## 八、薪资谈判要点（通用）

- **了解市场行情**：看准网/Levels.fyi/脉脉，目标公司同档位参考。
- **多拿 offer**：手里有多个 offer 才有底气谈。
- **报期望留空间**：报略高于心理预期 15-20%。
- **别先开价**：让对方先给范围。
- **总包思维**：base + 签字费 + 股票/期权 + 奖金 + 福利，不只看月薪。
- **股票归属**：注意 vesting 周期（通常 4 年）。
- **离职时机**：注意年终奖发放节点。

---

## 九、通用加分项（所有公司）

1. **了解目标公司技术栈/技术博客**（面试提一句"我看过你们的 XX 文章"加分）。
2. **开源贡献/技术博客/GitHub**（证明技术热情）。
3. **业务理解**（不只懂技术，懂业务价值）。
4. **提问环节问得好**（体现思考深度，见软素质文档）。
5. **稳定踏实 + 学习能力**（所有公司都喜欢）。

## 十、自测：你准备好了吗？

针对**每个目标公司类型**，自测：
- [ ] 我知道这类公司的面试重点。
- [ ] 我的项目能 match 这类公司的需求。
- [ ] 我针对性地准备了（算法/英语/八股/系统设计）。
- [ ] 我了解这类公司的薪资范围和流程。
- [ ] 我有针对性的反问问题。

> 💡 **建议**：先面**非首选公司**练手（独角兽/小厂），找手感；再面**外企/银行**（流程长先启动）；最后冲**大厂**（状态最佳时）。
