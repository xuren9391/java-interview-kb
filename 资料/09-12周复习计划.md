## 二、每日 2 小时怎么拆？（黄金模板）

在职每天只有 2 小时，**最忌讳"漫无目的看视频"**。建议按 **1+0.5+0.5** 拆：

```
┌─────────────────────────────────────────────┐
│  0:00-1:00  「输入」 看知识点/源码/文档（60min）│
│              → 配套本仓库 资料/ 对应章节         │
├─────────────────────────────────────────────┤
│  1:00-1:30  「输出」 默写要点+画图（30min）     │
│              → 关闭资料，手画流程图/默写原理     │
│              → 这一环节决定记不记得住           │
├─────────────────────────────────────────────┤
│  1:30-2:00  「算法」每天 1 题（30min）🌟 新增   │
│              → 大厂/外企硬门槛，必须每天坚持     │
│              → 按 算法/00 计划，专题推进         │
│              → 限时 Easy 15min / Medium 30min   │
└─────────────────────────────────────────────┘
```

> ⚠️ **铁律**：
> 1. 输出（默写）那 30 分钟不能省。光看不写，3 天后忘 70%。
> 2. **算法每天 30 分钟雷打不动**——大厂算法是硬门槛，断手感恢复很慢。
> 推荐用 **Anki**（间隔重复）把记不住的做成卡片，通勤/碎片时间刷。

> 📌 **算法专题进度**（每天 30min，对应 算法/00 学习路线）：
> W1 数组双指针 → W2 链表栈队列 → W3 哈希字符串 → W4 二叉树 → W5 二分排序 → W6 滑动窗口前缀和 → W7 回溯 → W8 动态规划 → W9 DP+堆TopK → W10 图BFS/DFS → W11 **手撕设计题** → W12 大厂真题模拟
