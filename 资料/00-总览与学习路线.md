# Java 资深/架构师 知识体系总览（对标 10 年档位）

> 适用对象：8 年工作经验、冲击「高级/资深开发 → 技术专家/架构师 → 研发经理」全线岗位
> 技术方向：Java 后端/微服务 · 高并发/高可用架构 · 基础架构/中间件 · AI Agent 应用
> 目标公司：互联网大厂 · 独角兽/中型公司 · 外企 · 国企/银行金融

## 一、能力模型（面试官真正考察的维度）

10 年档位的候选人，面试官不再只看你"背得多少"，而是看你**能不能扛事、能不能拍板、能不能带人**。考察维度按权重排序：

| 维度 | 权重 | 说明 |
|------|------|------|
| **项目深度与复盘能力** | ★★★★★ | 你做过的系统，每一个技术决策的「为什么」要能说清楚，包括踩坑、回滚、最终量化收益 |
| **系统设计能力** | ★★★★★ | 给一个开放命题，能否画出架构、说清取舍、识别风险（大厂/独角兽必考） |
| **底层原理** | ★★★★☆ | JVM、并发、MySQL、Redis、MQ 的原理要能讲到"源码/内核级"，而不是 API 级 |
| **分布式与高可用** | ★★★★☆ | CAP、一致性、限流熔断、容灾、多活——这是资深和初级最明显的分水岭 |
| **技术视野与选型** | ★★★☆☆ | 同类方案的横向对比（Kafka vs RocketMQ vs Pulsar），知道边界 |
| **稳定性建设** | ★★★☆☆ | 监控、报警、SOP、容量评估、故障复盘（外企/银行特别看重） |
| **工程素养与代码** | ★★★☆☆ | 设计模式、DDD、重构、Code Review、测试策略 |
| **技术影响力/带人** | ★★★☆☆ | 技术规划、人才培养、跨团队协作、技术布道（专家/架构师/管理岗必问） |
| **学习能力/新方向** | ★★☆☆☆ | AI Agent、云原生等新技术的理解深度（加分项） |

## 三、各模块重点速览（知识点难度分级）

> 🟢 必会（基础，答不上来直接挂） · 🟡 进阶（区分度） · 🔴 高阶（专家级加分）

### 1. Java 核心
- 🟢 集合体系（HashMap 源码、ConcurrentHashMap 分段锁演进）、并发三要素、volatile/synchronized 区别
- 🟡 JMM 内存模型、AQS 原理、线程池 7 参数 + 拒绝策略 + 合理配置、ThreadLocal 内存泄漏
- 🔴 JVM 内存模型（堆/元空间/直接内存）、GC 算法与收集器（G1/ZGC/Shenandoah）、调优实战、类加载与双亲委派破坏、CPU 100%/OOM 线上排查

### 2. Spring 与微服务
- 🟢 IoC/AOP 原理、Bean 生命周期、循环依赖三级缓存、SpringBoot 自动配置
- 🟡 Spring 启动流程、事务传播 7 种、@Transactional 失效场景、Nacos/ZK 注册中心对比
- 🔴 SpringCloud Alibaba 全家桶原理、Dubbo SPI vs Java SPI、服务网格 ServiceMesh/Istio、网关限流熔断落地

### 3. 数据库与存储
- 🟢 MySQL 索引（B+树/聚簇/覆盖/最左前缀）、事务隔离级别、MVCC、锁机制
- 🟡 explain 调优、分库分表（ShardingSphere）、主从延迟、Redis 5 种数据结构与持久化
- 🔴 InnoDB 源码级（Redo/Undo/Binlog 两阶段提交）、Redis 集群 gossip/槽迁移、缓存三大问题与布隆过滤器、ES 倒排索引与写入流程

### 4. 中间件与分布式
- 🟢 Kafka/RocketMQ 架构、消息可靠性、重复消费、顺序消息
- 🟡 分布式锁（Redis/ZK）、分布式事务（Seata/TCC/本地消息表/最大努力通知）、CAP/BASE
- 🔴 Raft/Paxos、MQ 存储引擎（CommitLog）、延时消息实现、分布式 ID 方案对比（雪花/Segment/Leaf）

### 5. 高并发高可用
- 🟢 缓存穿透/击穿/雪崩、限流算法（令牌桶/漏桶/滑动窗口）
- 🟡 熔断降级（Sentinel/Hystrix）、接口幂等、热点数据/热点账户、秒杀架构
- 🔴 全链路压测、异地多活（单元化/数据同步）、容量规划、稳定性 SOP、故障复盘方法论

### 6. 系统设计
- 🟢 短链系统、秒杀、Feed 流、排行榜
- 🟡 IM/消息推送、分布式文件系统、延迟任务平台、统一计费
- 🔴 美团/字节风格开放题：设计一个朋友圈、设计一个抢红包、亿级数据下报表系统

### 7. 架构师进阶
- 单体 → 集群 → 分布式 → 微服务 → 云原生 → ServiceMesh 演进
- DDD 落地（限界上下文/聚合根/防腐层）、康威定律、技术债管理
- 技术选型方法论（POC/基准测试/TCO）、团队管理、OKR、向上/向下管理

### 8. AI Agent（加分新方向）
- LLM 基础（Token/上下文窗口/幻觉/Function Calling）
- RAG 全链路（Embedding/向量库 Milvus/重排/Chunking）
- Agent 框架（LangChain/LlamaIndex/AutoGen/Dify/Coze）
- 工程化：Prompt 工程、评测体系、成本控制、与 Java 后端集成（Spring AI）

## 四、复习优先级建议（按 ROI 排序）

如果你时间有限，按这个顺序复习，性价比最高：

```
第一优先级（必拿分，1-2周）
  ① 项目复盘话术（STAR 法则，每个项目准备 3 个深度追问）
  ② JVM + 并发（几乎每场必问，且容易出彩）
  ③ MySQL + Redis（数据库是后端面试的基本盘）
  ④ Spring 原理（三级缓存、事务、自动配置是高频）

第二优先级（区分度，1-2周）
  ⑤ 分布式（事务/锁/一致性/MQ 可靠性）
  ⑥ 高并发场景题（秒杀/缓存三大问题/限流熔断）
  ⑦ 系统设计方法论 + 2-3 个经典设计题练手

第三优先级（加分项，按需）
  ⑧ 架构演进/技术选型/管理（冲专家/架构/管理岗必看）
  ⑨ AI Agent（简历有相关内容才需要深挖）
  ⑩ 网络/操作系统/算法（外企、字节会考，刷高频题即可）
```

## 五、面试准备 Checklist

面试前对照打勾，确保每个都过一遍：

- [ ] 简历上每个项目都能讲清：背景、架构图、你的角色、难点、方案取舍、量化结果、踩坑、复盘
- [ ] 准备 3-5 个"亮点项目"的深度故事（每场面试讲 1-2 个）
- [ ] JVM 调优、线上 OOM/CPU 高排查能完整说出步骤
- [ ] 至少手画过 3 个系统设计题的架构图（白板/纸笔）
- [ ] Redis、MySQL、MQ 的原理能讲到源码/内核级
- [ ] 准备好"反问面试官"的 3-5 个问题（体现思考深度）
- [ ] 了解目标公司的技术栈和近期技术博客（加分明显）
- [ ] 自我介绍 3 分钟版 + 1 分钟版（中文 + 英文，外企必备）
- [ ] 离职原因、期望薪资、职业规划三个"必答题"想清楚怎么说
