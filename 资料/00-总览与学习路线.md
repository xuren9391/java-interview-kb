## 一、能力模型（面试官真正考察的维度）

10 年档位的候选人，面试官不再只看你"背得多少"，而是看你**能不能扛事、能不能拍板、能不能带人**。考察维度按权重排序：

| 维度 | 权重 | 说明 |
|------|------|------|
| **项目深度与复盘能力** | ★★★★★ | 你做过的系统，每一个技术决策的「为什么」要能说清楚，包括踩坑、回滚、最终量化收益 |
| **系统设计能力** | ★★★★★ | 给一个开放命题，能否画出架构、说清取舍、识别风险（大厂/独角兽必考） |
| **底层原理** | ★★★★☆ | JVM、并发、MySQL、Redis、MQ 的原理要能讲到"源码/内核级"，而不是 API 级 |
| **分布式与高可用** | ★★★★☆ | CAP、一致性、限流熔断、容灾、多活——这是资深和初级最明显的分水岭 |
| **技术视野与选型** | ★★★☆☆ | 同类方案的横向对比（Kafka vs RocketMQ vs Pulsar），知道边界 |
| **稳定性建设** | ★★★☆☆ | 监控、报警、SOP、容量评估、故障复盘（外企/银行特别看重） |
| **工程素养与代码** | ★★★☆☆ | 设计模式、DDD、重构、Code Review、测试策略 |
| **技术影响力/带人** | ★★★☆☆ | 技术规划、人才培养、跨团队协作、技术布道（专家/架构师/管理岗必问） |
| **学习能力/新方向** | ★★☆☆☆ | AI Agent、云原生等新技术的理解深度（加分项） |

## 四、复习优先级建议（按 ROI 排序）

如果你时间有限，按这个顺序复习，性价比最高：

```
第一优先级（必拿分，1-2周）
  ① 项目复盘话术（STAR 法则，每个项目准备 3 个深度追问）

  ⑤ 分布式（事务/锁/一致性/MQ 可靠性）
  ⑥ 高并发场景题（秒杀/缓存三大问题/限流熔断）
  ⑦ 系统设计方法论 + 2-3 个经典设计题练手

第三优先级（加分项，按需）
  ⑧ 架构演进/技术选型/管理（冲专家/架构/管理岗必看）
  ⑨ AI Agent（简历有相关内容才需要深挖）
  ⑩ 网络/操作系统/算法（外企、字节会考，刷高频题即可）
```

## 五、面试准备 Checklist

面试前对照打勾，确保每个都过一遍：

- [ ] 简历上每个项目都能讲清：背景、架构图、你的角色、难点、方案取舍、量化结果、踩坑、复盘
- [ ] 准备 3-5 个"亮点项目"的深度故事（每场面试讲 1-2 个）
- [ ] JVM 调优、线上 OOM/CPU 高排查能完整说出步骤
- [ ] 至少手画过 3 个系统设计题的架构图（白板/纸笔）
- [ ] Redis、MySQL、MQ 的原理能讲到源码/内核级
- [ ] 准备好"反问面试官"的 3-5 个问题（体现思考深度）
- [ ] 了解目标公司的技术栈和近期技术博客（加分明显）
- [ ] 自我介绍 3 分钟版 + 1 分钟版（中文 + 英文，外企必备）
- [ ] 离职原因、期望薪资、职业规划三个"必答题"想清楚怎么说
