## 📅 使用建议

1. **先读** `资料/00-总览与学习路线.md` 和 `算法/00-学习路线与刷题计划.md`，建立全局认识。
2. **按 12 周计划执行**：`资料/09-12周复习计划.md`（每天技术 1.5h + 算法 0.5h）。
3. **面试前重点打磨**：`面试/面试题-项目复盘与STAR话术.md`（项目话术决定面试成败）。
4. **每场面试后**把新题/答不好的题补回对应文档，形成你的私人面经知识库。
