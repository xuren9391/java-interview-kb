#### 项目一：茶饮点单交易核心系统（高并发）⭐ 核心项目

**业务背景**：茶饮品牌小程序点单中台，覆盖下单、支付、订单履约全链路。午晚高峰 + 新品大促（如联名活动、首杯免费）带来瞬时流量洪峰，峰值 QPS 回头补充（近百万家门店规模）。

**技术栈**：SpringCloud Alibaba + SpringBoot + MyBatis-Plus + MySQL（分库分表）+ Redis 集群 + RocketMQ + Sentinel + ShardingSphere + SkyWalking

**核心贡献**：

- **核心交易链路开发**：主导购物车、下单、支付、订单查询核心流程，保障**交易数据一致性**（支付成功 ↔ 订单状态 ↔ 门店接单）。
  - 基于 **RocketMQ 事务消息** 解决"支付成功 + 订单状态更新"的分布式一致性问题。
  - 设计**接口幂等**方案（Token + 去重表），防止网络重试导致的重复扣款/重复下单。
- **高并发点单优化**（亮点）：
  - **缓存改造**：门店/商品/库存等热点数据多级缓存（Caffeine 本地 + Redis），高峰期缓存命中率达 85%，DB 压力显著下降。
  - **库存扣减**：基于 Redis + Lua 原子预扣（拦 99% 超卖请求）+ DB 乐观锁兜底（`WHERE stock > 0`），彻底解决大促超卖。
  - **异步削峰**：订单创建后非核心链路（通知门店、营销触达、统计）改 RocketMQ 异步，主链路 RT 从 2s 降至 400ms（高峰缓存命中率达 85%）。
  - **限流降级**：Sentinel 按门店/接口维度限流，大促开启兜底降级（关闭非核心推荐），保障核心点单可用。
- **性能调优实战**：排查并解决线上 FullGC 频繁（本地缓存无淘汰导致内存泄漏，改 Caffeine + 换 G1）、慢 SQL（加联合索引 + 覆盖索引，RT 从 2s→80ms）、Redis 热 Key（多副本分摊）。
- **稳定性建设**：搭建 SkyWalking 全链路监控 + 核心接口告警 + 故障预案 SOP，线上故障 MTTR（平均恢复时间）下降 50%。

#### 项目三：门店商品 SaaS（多租户架构）⭐ 架构亮点

**业务背景**：为不同餐饮品牌（租户）提供门店、商品、库存、价格的管理能力，要求**租户间数据严格隔离** + **支持租户级个性化配置**。

**核心贡献**：

- **数据隔离与安全**：通过 MyBatis-Plus 多租户插件 + 网关层租户解析，确保**任何 SQL 自动带 tenant_id**，杜绝跨租户数据泄漏（曾发现并修复 2 处潜在越权风险）。
- **租户级配置**：基于策略模式 + 配置中心（Nacos），支持不同品牌的差异化业务规则（不同计费、不同流程）热更新。
