# 一、LRU 缓存 🔴🔴🔴（最高频，必背！）

**题目**（LC 146）：设计一个支持 `get(key)` 和 `put(key, value)` 的数据结构，容量超限时淘汰**最久未使用**的。两个操作都要 **O(1)**。

## 1.1 思路分析
- O(1) 查找 → **HashMap**。
- O(1) 维护访问顺序 → **双向链表**（删除/插入节点 O(1)，只需改指针）。
- 访问/写入时把节点移到链表头部，淘汰时删尾部（最久未用）。

## 1.2 🔴 完整实现（背这版）
```java
class LRUCache {
    // 双向链表节点
    class Node {
        int key, val;
        Node prev, next;
        Node(int k, int v) { key = k; val = v; }
    }
    private int capacity, size;
    private Map<Integer, Node> map = new HashMap<>();
    private Node head, tail;  // 虚拟头尾（避免空指针）

    public LRUCache(int capacity) {
        this.capacity = capacity;
        head = new Node(0, 0);
        tail = new Node(0, 0);
        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        if (!map.containsKey(key)) return -1;
        Node node = map.get(key);
        moveToHead(node);              // 访问后移到头部
        return node.val;
    }

    public void put(int key, int value) {
        if (map.containsKey(key)) {
            Node node = map.get(key);
            node.val = value;
            moveToHead(node);
        } else {
            Node node = new Node(key, value);
            map.put(key, node);
            addToHead(node);
            size++;
            if (size > capacity) {
                Node removed = removeTail();   // 淘汰尾部
                map.remove(removed.key);       // 别忘从 map 删！
                size--;
            }
        }
    }

    private void addToHead(Node node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }
    private void removeNode(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
    private void moveToHead(Node node) {
        removeNode(node);
        addToHead(node);
    }
    private Node removeTail() {
        Node node = tail.prev;
        removeNode(node);
        return node;
    }
}
```

## 1.3 易错点 🔴
- **虚拟头尾节点**：避免空指针，大幅简化边界处理（必加！）。
- **淘汰时要从 map 也删掉**（用 key，所以 Node 要存 key）。
- **get 也要 moveToHead**（访问也算"使用"）。

## 1.4 追问
- **Java 自带实现**：`LinkedHashMap`（重写 `removeEldestEntry`），但面试要你手写。
- **线程安全**：加锁 / 用 `ConcurrentHashMap` + 同步。
- **淘汰策略变 LFU**：见下。

# 二、LFU 缓存 🔴（Hard，进阶）

**题目**（LC 460）：淘汰**访问频率最低**的（频率相同则淘汰最久未用的）。O(1)。

## 2.1 思路
- 两个 Map：`keyToNode`（key→节点）、`freqToList`（频率→双向链表，存该频率的所有节点，最近访问的在头）。
- `minFreq` 记录当前最小频率。
- 访问：从旧频率链表删除，加到新频率链表头，更新 minFreq。

## 2.2 实现（略，参考 LC 460 题解）
核心：频率链表 + minFreq。淘汰时从 `freqToList.get(minFreq)` 的尾部删。

# 三、限流器 🔴🔴（令牌桶 + 滑动窗口）

## 3.1 令牌桶（单机）
```java
class TokenBucket {
    private final long capacity;       // 桶容量
    private final double rate;         // 每秒生成令牌数
    private double tokens;             // 当前令牌
    private long lastRefillNanos;

    public TokenBucket(long capacity, double rate) {
        this.capacity = capacity;
        this.rate = rate;
        this.tokens = capacity;
        this.lastRefillNanos = System.nanoTime();
    }
    public synchronized boolean tryAcquire() {
        long now = System.nanoTime();
        double elapsed = (now - lastRefillNanos) / 1e9;
        tokens = Math.min(capacity, tokens + elapsed * rate);  // 按时间补充
        lastRefillNanos = now;
        if (tokens >= 1) { tokens -= 1; return true; }
        return false;
    }
}
```

## 3.2 滑动窗口限流（Sentinel 思路）
```java
class SlidingWindowRateLimiter {
    private final int limit;
    private final long windowMs;
    private final AtomicLong[] buckets;   // 子桶计数
    private final long bucketMs;
    private volatile long startTime;

    public SlidingWindowRateLimiter(int limit, long windowMs, int sampleCount) {
        this.limit = limit;
        this.windowMs = windowMs;
        this.bucketMs = windowMs / sampleCount;
        this.buckets = new AtomicLong[sampleCount];
        for (int i = 0; i < sampleCount; i++) buckets[i] = new AtomicLong();
        startTime = System.currentTimeMillis();
    }
    public synchronized boolean tryAcquire() {
        long now = System.currentTimeMillis();
        long elapsedBuckets = (now - startTime) / bucketMs;
        if (elapsedBuckets >= buckets.length) {
            // 窗口过期，重置
            for (AtomicLong b : buckets) b.set(0);
            startTime = now;
        }
        long total = 0;
        for (AtomicLong b : buckets) total += b.get();
        if (total >= limit) return false;
        int idx = (int)(((now - startTime) / bucketMs) % buckets.length);
        buckets[idx].incrementAndGet();
        return true;
    }
}
```

# 四、生产者-消费者 🔴🔴（必背）

## 4.1 synchronized + wait/notify 版
```java
class BoundedBuffer<T> {
    private final Queue<T> queue = new LinkedList<>();
    private final int capacity;
    public BoundedBuffer(int capacity) { this.capacity = capacity; }

    public synchronized void put(T item) throws InterruptedException {
        while (queue.size() == capacity) wait();   // 满，等（用 while 防虚假唤醒）
        queue.offer(item);
        notifyAll();                                // 通知消费者
    }
    public synchronized T take() throws InterruptedException {
        while (queue.isEmpty()) wait();            // 空，等
        T item = queue.poll();
        notifyAll();                                // 通知生产者
        return item;
    }
}
```

## 4.2 🔴 Lock + Condition 版（更优，两个条件队列）
```java
class BoundedBuffer<T> {
    private final Queue<T> queue = new LinkedList<>();
    private final int capacity;
    private final ReentrantLock lock = new ReentrantLock();
    private final Condition notFull = lock.newCondition();
    private final Condition notEmpty = lock.newCondition();

    public BoundedBuffer(int capacity) { this.capacity = capacity; }

    public void put(T item) throws InterruptedException {
        lock.lock();
        try {
            while (queue.size() == capacity) notFull.await();
            queue.offer(item);
            notEmpty.signal();                      // 精准唤醒（只通知消费者）
        } finally { lock.unlock(); }
    }
    public T take() throws InterruptedException {
        lock.lock();
        try {
            while (queue.isEmpty()) notEmpty.await();
            T item = queue.poll();
            notFull.signal();
            return item;
        } finally { lock.unlock(); }
    }
}
```
**为什么用 while 不用 if？** 🔴 防止**虚假唤醒**（spurious wakeup）+ 多线程被唤醒后条件可能已被其他线程改变。

## 4.3 BlockingQueue 版（生产推荐）
```java
BlockingQueue<Task> queue = new ArrayBlockingQueue<>(100);
// 生产者
queue.put(task);
// 消费者
Task task = queue.take();
```

# 五、阻塞队列 🔴

手写一个简单的 `ArrayBlockingQueue`：
```java
class MyBlockingQueue<T> {
    private final Object[] items;
    private int takeIndex, putIndex, count;
    private final ReentrantLock lock = new ReentrantLock();
    private final Condition notFull = lock.newCondition();
    private final Condition notEmpty = lock.newCondition();

    public MyBlockingQueue(int capacity) { items = new Object[capacity]; }

    public void put(T item) throws InterruptedException {
        lock.lockInterruptibly();
        try {
            while (count == items.length) notFull.await();
            items[putIndex] = item;
            if (++putIndex == items.length) putIndex = 0;
            count++;
            notEmpty.signal();
        } finally { lock.unlock(); }
    }
    @SuppressWarnings("unchecked")
    public T take() throws InterruptedException {
        lock.lockInterruptibly();
        try {
            while (count == 0) notEmpty.await();
            T item = (T) items[takeIndex];
            items[takeIndex] = null;
            if (++takeIndex == items.length) takeIndex = 0;
            count--;
            notFull.signal();
            return item;
        } finally { lock.unlock(); }
    }
}
```

# 七、单例模式 🔴（必背 5 种）

## 7.1 双重检查 DCL（推荐，必背）
```java
public class Singleton {
    private static volatile Singleton instance;   // volatile 必加！
    private Singleton() {}
    public static Singleton getInstance() {
        if (instance == null) {                   // 第一次检查（避免每次加锁）
            synchronized (Singleton.class) {
                if (instance == null) {            // 第二次检查
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}
```
**为什么 volatile？** 见 Java 核心篇 2.2（new 非原子，重排导致拿到未初始化对象）。

## 7.2 静态内部类（最优雅，推荐）
```java
public class Singleton {
    private Singleton() {}
    private static class Holder {
        static final Singleton INSTANCE = new Singleton();   // 懒加载 + 线程安全
    }
    public static Singleton getInstance() { return Holder.INSTANCE; }
}
```
**原理**：JVM 保证类加载线程安全，Holder 在 getInstance 时才加载（懒）。

## 7.3 枚举（Effective Java 推荐，防反射）
```java
public enum Singleton {
    INSTANCE;
}
```

# 八、跳表（SkipList）🔴（Redis ZSet 底层）

手写简化版（了解原理）：
```java
class SkipListNode {
    int val;
    SkipListNode[] next;   // 多层指针
    SkipListNode(int val, int level) { this.val = val; next = new SkipListNode[level]; }
}
class SkipList {
    private static final int MAX_LEVEL = 16;
    private SkipListNode head = new SkipListNode(-1, MAX_LEVEL);
    private int level = 1;
    private Random random = new Random();

    public boolean search(int target) { /* 从最高层向右走，走不动下降 */ }
    public void add(int num) { /* 随机层数，逐层插入 */ }
    public boolean erase(int num) { /* 逐层删除 */ }

    private int randomLevel() {
        int lvl = 1;
        while (random.nextInt(2) == 1 && lvl < MAX_LEVEL) lvl++;
        return lvl;
    }
}
```
**关键**：层数随机生成（p=0.5 升一级），查询 O(log N)。
