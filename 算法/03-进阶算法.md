# 一、回溯（Backtracking）🔴 必背模板

## 1.1 适用场景
- **全排列、组合、子集、所有方案**。
- 本质：**DFS 搜索所有可能**，不行就回退（撤销选择）。

## 1.2 🔴 万能模板（必背）
```java
void backtrack(路径, 选择列表) {
    if (满足结束条件) {
        res.add(路径的副本);    // 注意要拷贝！
        return;
    }
    for (选择 : 选择列表) {
        做选择;                 // 加入路径
        backtrack(路径, 选择列表);
        撤销选择;               // 移出路径（回溯）
    }
}
```

**核心心法**：回溯 = **做选择 → 递归 → 撤销选择**，画决策树理解。

## 1.3 经典题

**全排列**（LC 46，必背）：
```java
List<List<Integer>> res = new ArrayList<>();
public List<List<Integer>> permute(int[] nums) {
    backtrack(nums, new ArrayList<>(), new boolean[nums.length]);
    return res;
}
void backtrack(int[] nums, List<Integer> path, boolean[] used) {
    if (path.size() == nums.length) { res.add(new ArrayList<>(path)); return; }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) continue;
        path.add(nums[i]); used[i] = true;       // 做选择
        backtrack(nums, path, used);
        path.remove(path.size() - 1); used[i] = false;  // 撤销
    }
}
```

**子集**（LC 78）：
```java
List<List<Integer>> res = new ArrayList<>();
public List<List<Integer>> subsets(int[] nums) {
    dfs(nums, 0, new ArrayList<>());
    return res;
}
void dfs(int[] nums, int start, List<Integer> path) {
    res.add(new ArrayList<>(path));           // 每个节点都是一个子集
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        dfs(nums, i + 1, path);               // 注意 i+1（不回头）
        path.remove(path.size() - 1);
    }
}
```

**组合**（LC 77，k 个数的组合）：和子集几乎一样，只在 `path.size() == k` 时加入。

**组合总和**（LC 39，元素可重复使用）：
```java
void dfs(int[] candidates, int target, int start, List<Integer> path) {
    if (target == 0) { res.add(new ArrayList<>(path)); return; }
    for (int i = start; i < candidates.length; i++) {
        if (candidates[i] > target) continue;       // 剪枝
        path.add(candidates[i]);
        dfs(candidates, target - candidates[i], i, path);  // i 不是 i+1（可重复）
        path.remove(path.size() - 1);
    }
}
```

**N 皇后**（LC 51，经典 Hard）：
```java
// 在每一行放皇后，列、对角线不能冲突
// 用 Set 记录已占用的列、主对角(row-col)、副对角(row+col)
```

## 1.4 🔴 剪枝（提升效率）
- 排序后跳过不合理的分支（如组合总和 `candidates[i] > target` 跳过）。
- 去重：排序后 `if (i > start && nums[i] == nums[i-1]) continue`（同层跳过重复）。

# 二、动态规划（DP）🔴🔴 必精通（高频高分）

## 2.1 核心思想
- 把问题拆成**重叠子问题**，**记忆化**避免重复计算。
- 三要素：
  1. **状态定义**：`dp[i]` 或 `dp[i][j]` 代表什么？
  2. **状态转移方程**：`dp[i]` 怎么从前面的 dp 推出？
  3. **初始条件 + 边界**。

## 2.2 DP 解题步骤 🔴
```
1. 定义状态 dp[...]（想清楚"是什么"）
2. 写转移方程 dp[i] = f(dp[i-1], ...)
3. 初始值 dp[0] = ?, 边界
4. 计算顺序（通常从小到大）
5. 返回答案
```

## 2.3 经典题（按类型）

### ① 一维 DP

**爬楼梯**（LC 70，入门）：
```java
// dp[i] = dp[i-1] + dp[i-2]
public int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) { int c = a + b; a = b; b = c; }
    return b;
}
```

**打家劫舍**（LC 198）：
```java
// dp[i] = max(dp[i-1], dp[i-2] + nums[i])  // 偷或不偷
public int rob(int[] nums) {
    int prev2 = 0, prev1 = 0;
    for (int n : nums) {
        int cur = Math.max(prev1, prev2 + n);
        prev2 = prev1; prev1 = cur;
    }
    return prev1;
}
```

**最长递增子序列 LIS**（LC 300）：
```java
// O(n²)：dp[i] = max(dp[j]+1) for j<i and nums[j]<nums[i]
public int lengthOfLIS(int[] nums) {
    int[] dp = new int[nums.length];
    Arrays.fill(dp, 1);
    int max = 1;
    for (int i = 1; i < nums.length; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
        }
        max = Math.max(max, dp[i]);
    }
    return max;
}
// 进阶 O(n log n)：二分 + 贪心（patience sorting）
```

### ② 二维 DP / 子序列

**最长公共子序列 LCS**（LC 1143）：
```java
// dp[i][j] = s1[0..i] 与 s2[0..j] 的 LCS 长度
public int longestCommonSubsequence(String s1, String s2) {
    int m = s1.length(), n = s2.length();
    int[][] dp = new int[m+1][n+1];
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1.charAt(i-1) == s2.charAt(j-1)) dp[i][j] = dp[i-1][j-1] + 1;
            else dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
        }
    }
    return dp[m][n];
}
```

**编辑距离**（LC 72，经典 Hard）：
```java
// dp[i][j] = word1[0..i] 转成 word2[0..j] 的最少操作数
// 相等：dp[i-1][j-1]
// 不等：min(增 dp[i][j-1], 删 dp[i-1][j], 替 dp[i-1][j-1]) + 1
```

### ③ 背包 DP 🔴

**0-1 背包**（每件物品用 0 或 1 次）：
```java
// dp[j] = 容量 j 能装的最大价值
for (int i = 0; i < n; i++)              // 遍历物品
    for (int j = W; j >= weight[i]; j--) // 倒序遍历容量！（防重复用）
        dp[j] = Math.max(dp[j], dp[j-weight[i]] + value[i]);
```

**完全背包**（物品无限用）：
```java
for (int i = 0; i < n; i++)
    for (int j = weight[i]; j <= W; j++) // 正序！（可重复）
        dp[j] = Math.max(dp[j], dp[j-weight[i]] + value[i]);
```

**零钱兑换**（LC 322，完全背包求最少硬币数）：
```java
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);
    dp[0] = 0;
    for (int i = 1; i <= amount; i++)
        for (int c : coins)
            if (c <= i) dp[i] = Math.min(dp[i], dp[i - c] + 1);
    return dp[amount] > amount ? -1 : dp[amount];
}
```

### ④ 股票问题（状态机 DP）
**买卖股票最佳时机**（LC 121，一次交易）：
```java
public int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE, maxProfit = 0;
    for (int p : prices) {
        minPrice = Math.min(minPrice, p);
        maxProfit = Math.max(maxProfit, p - minPrice);
    }
    return maxProfit;
}
```
多次交易（LC 122）、含手续费/冷冻期（LC 714/309）用状态机 DP（hold/nothold 两个状态）。

## 2.4 🔴 DP 优化思路
- **空间压缩**：dp[i] 只依赖 dp[i-1]，用两个变量滚动。
- **滚动数组**：`dp[i&1]` 替代二维。
- **状态压缩**：位运算（如旅行商问题）。

# 三、图（Graph）

## 3.1 表示
- **邻接矩阵** `g[i][j]`：稠密图，O(V²) 空间。
- **邻接表** `List<Integer>[]`：稀疏图，O(V+E) 空间（推荐）。

## 3.2 BFS（广度优先）🔴
- 用**队列**，一层层扩展。
- **求最短路径/最少步数**（无权图）。
- 模板：
```java
Queue<int[]> queue = new LinkedList<>();
queue.offer(start);
boolean[] visited = new boolean[n];
visited[start] = true;
int step = 0;
while (!queue.isEmpty()) {
    int size = queue.size();
    for (int i = 0; i < size; i++) {       // 一次处理一层
        int cur = queue.poll();
        if (cur == target) return step;     // 找到
        for (int next : adj[cur]) {
            if (!visited[next]) { visited[next] = true; queue.offer(next); }
        }
    }
    step++;
}
```

## 3.3 DFS（深度优先）
- 用**递归/栈**，一条路走到底再回退。
- **求所有路径、连通性、拓扑**。
```java
void dfs(int cur, boolean[] visited) {
    if (visited[cur]) return;
    visited[cur] = true;
    for (int next : adj[cur]) dfs(next, visited);
}
```

## 3.4 经典题

**岛屿数量**（LC 200，DFS/BFS 标记）：
```java
public int numIslands(char[][] grid) {
    int count = 0;
    for (int i = 0; i < grid.length; i++)
        for (int j = 0; j < grid[0].length; j++)
            if (grid[i][j] == '1') { dfs(grid, i, j); count++; }
    return count;
}
void dfs(char[][] g, int i, int j) {
    if (i < 0 || i >= g.length || j < 0 || j >= g[0].length || g[i][j] != '1') return;
    g[i][j] = '0';   // 标记访问
    dfs(g, i+1, j); dfs(g, i-1, j); dfs(g, i, j+1); dfs(g, i, j-1);
}
```

**单词搜索**（LC 79，回溯 + DFS）。

**课程表**（LC 207，拓扑排序）：
```java
// 拓扑排序：BFS，入度为 0 的先入队，处理时减相邻节点入度
public boolean canFinish(int n, int[][] prerequisites) {
    int[] indegree = new int[n];
    List<List<Integer>> adj = new ArrayList<>();
    for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
    for (int[] p : prerequisites) { adj.get(p[1]).add(p[0]); indegree[p[0]]++; }
    Queue<Integer> q = new LinkedList<>();
    for (int i = 0; i < n; i++) if (indegree[i] == 0) q.offer(i);
    int count = 0;
    while (!q.isEmpty()) {
        int cur = q.poll(); count++;
        for (int next : adj.get(cur)) if (--indegree[next] == 0) q.offer(next);
    }
    return count == n;
}
```

# 四、单调栈（Monotonic Stack）🟡

## 4.1 适用
- **下一个更大/更小元素**。
- 维护**单调递增/递减**的栈。

## 4.2 模板（下一个更大元素，LC 496/739）🔴
```java
public int[] nextGreaterElement(int[] nums) {
    int[] res = new int[nums.length];
    Arrays.fill(res, -1);
    Deque<Integer> st = new ArrayDeque<>();  // 存下标
    for (int i = 0; i < nums.length; i++) {
        while (!st.isEmpty() && nums[st.peek()] < nums[i]) {
            res[st.pop()] = nums[i];   // 栈顶元素的"下一个更大"是 nums[i]
        }
        st.push(i);
    }
    return res;
}
```

**每日温度**（LC 739）：同理，存下标，差值就是天数。

# 五、单调队列（Monotonic Queue）🟡

## 5.1 适用
- **滑动窗口最大/最小值**。

## 5.2 模板（滑动窗口最大值，LC 239）
```java
public int[] maxSlidingWindow(int[] nums, int k) {
    int[] res = new int[nums.length - k + 1];
    Deque<Integer> dq = new ArrayDeque<>();   // 存下标，单调递减
    for (int i = 0; i < nums.length; i++) {
        while (!dq.isEmpty() && dq.peekFirst() <= i - k) dq.pollFirst();  // 出窗口
        while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i]) dq.pollLast(); // 保持递减
        dq.offerLast(i);
        if (i >= k - 1) res[i - k + 1] = nums[dq.peekFirst()];
    }
    return res;
}
```

# 六、并查集（Union-Find）🟡

## 6.1 适用
- **连通性**、**集合合并**、**最小生成树（Kruskal）**。

## 6.2 模板（带路径压缩 + 按秩合并）🔴
```java
class UnionFind {
    int[] parent, rank;
    int count;  // 连通分量数
    UnionFind(int n) {
        parent = new int[n]; rank = new int[n]; count = n;
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);  // 路径压缩
        return parent[x];
    }
    void union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return;
        if (rank[px] < rank[py]) parent[px] = py;
        else if (rank[px] > rank[py]) parent[py] = px;
        else { parent[py] = px; rank[px]++; }
        count--;
    }
    boolean connected(int x, int y) { return find(x) == find(y); }
}
```
**复杂度**：近似 O(1)（阿克曼反函数）。

**例题**：LC 200 岛屿数量（也可并查集）、LC 128 最长连续序列、LC 547 省份数量。

# 七、前缀树 / 字典树（Trie）🟡

```java
class Trie {
    Trie[] children = new Trie[26];
    boolean isEnd;
    void insert(String word) {
        Trie node = this;
        for (char c : word.toCharArray()) {
            int i = c - 'a';
            if (node.children[i] == null) node.children[i] = new Trie();
            node = node.children[i];
        }
        node.isEnd = true;
    }
    boolean search(String word) { /* 遍历到末尾查 isEnd */ }
    boolean startsWith(String prefix) { /* 遍历即可 */ }
}
```

# 八、算法选择速查 🔴

| 问题特征 | 选什么 |
|---------|--------|
| 求最短路径/最少步数（无权） | BFS |
