# 一、双指针（Two Pointers）

## 1.1 适用场景
- **有序数组**找两数之和/三数之和。
- **原地修改**数组（去重、移除元素）。
- **链表**找中点/环/倒数。

## 1.2 三种模式 🔴

### ① 对撞指针（左右相向）
```
[1,2,3,4,5,6]   有序数组两数之和
 l           r
l+r < target → l++
l+r > target → r--
l+r == target → 找到
```
**模板**：
```java
int l = 0, r = n - 1;
while (l < r) {
    int sum = a[l] + a[r];
    if (sum == target) { /* 找到 */ break; }
    else if (sum < target) l++;
    else r--;
}
```
**例题**：LC 167 两数之和 II（有序）、LC 11 盛最多水的容器、LC 15 三数之和。

### ② 快慢指针（同向）
```
slow 指向"应放的位置"，fast 扫描
适合：原地修改、去重、移除
```
**模板**（见数据结构篇"移动零"）：
```java
int slow = 0;
for (int fast = 0; fast < n; fast++) {
    if (满足条件) { swap/赋值 a[slow], a[fast]; slow++; }
}
```
**例题**：LC 26 删除有序数组重复项、LC 283 移动零、LC 27 移除元素。

### ③ 链表快慢指针
- 找中点、判断环、找环入口、倒数第 k。

## 1.3 经典题

**三数之和**（LC 15，必背，高频）：
```java
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    Arrays.sort(nums);
    for (int i = 0; i < nums.length - 2; i++) {
        if (nums[i] > 0) break;                     // 最小>0，不可能=0
        if (i > 0 && nums[i] == nums[i-1]) continue; // 去重
        int l = i + 1, r = nums.length - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (sum == 0) {
                res.add(Arrays.asList(nums[i], nums[l], nums[r]));
                while (l < r && nums[l] == nums[l+1]) l++;  // 去重
                while (l < r && nums[r] == nums[r-1]) r--;
                l++; r--;
            } else if (sum < 0) l++;
            else r--;
        }
    }
    return res;
}
```

**盛最多水的容器**（LC 11）：
```java
public int maxArea(int[] h) {
    int l = 0, r = h.length - 1, max = 0;
    while (l < r) {
        max = Math.max(max, Math.min(h[l], h[r]) * (r - l));
        if (h[l] < h[r]) l++; else r--;   // 移动较矮的
    }
    return max;
}
```

# 二、滑动窗口（Sliding Window）🔴 必背模板

## 2.1 适用场景
- **连续子数组/子串**问题（和/积/最长/最短/含某些字符）。

## 2.2 🔴 万能模板（记住这版）
```java
int left = 0, ans = 0;
Map<Character,Integer> need = ..., window = ...;  // 或用计数数组
int valid = 0;  // 满足条件的字符数

for (int right = 0; right < s.length(); right++) {
    char c = s.charAt(right);
    // 1. 右扩：c 加入窗口
    //    更新 window、valid

    while (窗口需要收缩) {        // 2. 判断何时收缩
        // 3. 更新答案（窗口合法时）
        char d = s.charAt(left++);
        // 4. 左缩：d 移出窗口
        //    更新 window、valid
    }
    // 也可能在这更新答案（求最长 vs 最短）
}
return ans;
```

**两类问题**：
- **求最长**（无重复字符的最长子串）：右扩，不满足时左缩，**扩完更新答案**。
- **求最短**（最小覆盖子串）：右扩到满足，然后左缩到不满足，**缩之前更新答案**。

## 2.3 经典题

**无重复字符的最长子串**（LC 3，必背）：
```java
public int lengthOfLongestSubstring(String s) {
    Map<Character,Integer> last = new HashMap<>();
    int left = 0, max = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (last.containsKey(c) && last.get(c) >= left) {
            left = last.get(c) + 1;   // 跳过重复字符
        }
        last.put(c, right);
        max = Math.max(max, right - left + 1);
    }
    return max;
}
```

**最小覆盖子串**（LC 76，Hard 但套路典型）：
```java
public String minWindow(String s, String t) {
    Map<Character,Integer> need = new HashMap<>(), window = new HashMap<>();
    for (char c : t.toCharArray()) need.merge(c, 1, Integer::sum);
    int left = 0, valid = 0, start = 0, minLen = Integer.MAX_VALUE;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (need.containsKey(c)) {
            window.merge(c, 1, Integer::sum);
            if (window.get(c).intValue() == need.get(c).intValue()) valid++;
        }
        while (valid == need.size()) {   // 满足，尝试收缩
            if (right - left + 1 < minLen) { minLen = right - left + 1; start = left; }
            char d = s.charAt(left++);
            if (need.containsKey(d)) {
                if (window.get(d).intValue() == need.get(d).intValue()) valid--;
                window.merge(d, -1, Integer::sum);
            }
        }
    }
    return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
}
```

# 三、二分查找（Binary Search）🔴 必背模板

## 3.1 适用场景
- **有序数组**查找。
- **答案的边界**（如"满足某条件的最大值"）。
- 求最值时的"二分答案"。

## 3.2 🔴 三种变体（必背，边界是重点）

**① 标准二分（找精确值）**：
```java
int search(int[] a, int target) {
    int l = 0, r = a.length - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;   // 防溢出
        if (a[mid] == target) return mid;
        else if (a[mid] < target) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}
```

**② 找左边界（第一个 >= target）**：
```java
// 返回第一个 >= target 的位置（也可理解为插入位置）
int lowerBound(int[] a, int target) {
    int l = 0, r = a.length;       // 注意 r = length（开区间）
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] < target) l = mid + 1;
        else r = mid;              // 收缩右边界
    }
    return l;
}
```

**③ 找右边界（最后一个 <= target）**：
```java
int upperBound(int[] a, int target) {
    int l = 0, r = a.length;
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (a[mid] <= target) l = mid + 1;
        else r = mid;
    }
    return l - 1;                  // 或返回 l（第一个 > target 的位置）
}
```

## 3.3 易错点 🔴
- **死循环**：`mid` 更新要 `l = mid + 1` 而不是 `l = mid`（否则死循环）。
- **溢出**：`mid = l + (r-l)/2`。
- **循环条件**：`l <= r`（精确）vs `l < r`（边界）。

## 3.4 经典题

**搜索旋转排序数组**（LC 33，必背）：
```java
public int search(int[] nums, int target) {
    int l = 0, r = nums.length - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] == target) return mid;
        if (nums[l] <= nums[mid]) {              // 左半有序
            if (nums[l] <= target && target < nums[mid]) r = mid - 1;
            else l = mid + 1;
        } else {                                 // 右半有序
            if (nums[mid] < target && target <= nums[r]) l = mid + 1;
            else r = mid - 1;
        }
    }
    return -1;
}
```

# 四、前缀和与差分

## 4.1 一维前缀和
- **preSum[i] = a[0] + ... + a[i-1]**（preSum[0]=0）。
- 区间和 `[l, r]` = `preSum[r+1] - preSum[l]`，O(1)。

```java
int[] preSum = new int[n + 1];
for (int i = 0; i < n; i++) preSum[i+1] = preSum[i] + a[i];
int rangeSum = preSum[r+1] - preSum[l];
```
**例题**：LC 303 区域和检索、LC 560 和为 K 的子数组（前缀和+哈希）。

**和为 K 的子数组**（LC 560，前缀和+哈希优化）：
```java
public int subarraySum(int[] nums, int k) {
    Map<Integer,Integer> prefixCount = new HashMap<>();
    prefixCount.put(0, 1);  // 前缀和为 0 出现 1 次
    int sum = 0, count = 0;
    for (int n : nums) {
        sum += n;
        count += prefixCount.getOrDefault(sum - k, 0);  // 找之前有没有 sum-k
        prefixCount.merge(sum, 1, Integer::sum);
    }
    return count;
}
```

## 4.2 二维前缀和
- `preSum[i][j]` = 左上角 (0,0) 到 (i-1,j-1) 的矩形和。
- 子矩阵 (r1,c1)~(r2,c2) 的和：
  `preSum[r2+1][c2+1] - preSum[r1][c2+1] - preSum[r2+1][c1] + preSum[r1][c1]`。

## 4.3 差分（前缀和的逆运算）
- 对区间 `[l,r]` 都加 v：`diff[l] += v; diff[r+1] -= v`，最后求前缀和还原。
- 适合"多次区间修改、一次查询"。

# 五、排序算法 🔴（必懂 + 手写快排归并）

## 5.1 对比表

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 特点 |
|------|------|------|------|------|------|
| 冒泡 | O(n²) | O(n²) | O(1) | ✅ | 简单 |
| 选择 | O(n²) | O(n²) | O(1) | ❌ | 少 |
| 插入 | O(n²) | O(n²) | O(1) | ✅ | 小数据/近乎有序快 |
| **快排** | O(n log n) | O(n²) | O(log n) | ❌ | **实践最快** |
| **归并** | O(n log n) | O(n log n) | O(n) | ✅ | 稳定、外排序 |
| **堆排** | O(n log n) | O(n log n) | O(1) | ❌ | 原地 |

**稳定**：相等元素的相对顺序不变。归并/计数/基数/冒泡/插入稳定。

## 5.2 快速排序（必背，手写）🔴
```java
void quickSort(int[] a, int l, int r) {
    if (l >= r) return;
    int p = partition(a, l, r);
    quickSort(a, l, p - 1);
    quickSort(a, p + 1, r);
}
int partition(int[] a, int l, int r) {
    int pivot = a[r], i = l;
    for (int j = l; j < r; j++) {
        if (a[j] < pivot) {
            int t = a[i]; a[i] = a[j]; a[j] = t;  // swap(a,i,j)
            i++;
        }
    }
    int t = a[i]; a[i] = a[r]; a[r] = t;          // swap(a,i,r)
    return i;
}
```

## 5.3 归并排序（必背，手写 + 用于"逆序对"）🔴
```java
void mergeSort(int[] a, int l, int r) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    mergeSort(a, l, m);
    mergeSort(a, m + 1, r);
    merge(a, l, m, r);
}
void merge(int[] a, int l, int m, int r) {
    int[] tmp = new int[r - l + 1];
    int i = l, j = m + 1, k = 0;
    while (i <= m && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else tmp[k++] = a[j++];
    }
    while (i <= m) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    System.arraycopy(tmp, 0, a, l, tmp.length);
}
```
**应用**：**逆序对**（LC 剑指 51）—— merge 时 `a[i] > a[j]`，则 `a[i..m]` 都和 `a[j]` 构成逆序对，计数 += `m-i+1`。

## 5.4 堆排序（理解）
- 建堆（从 n/2 到 0 下沉）→ 每次把堆顶换到末尾，缩小堆，下沉。

## 5.5 Java 排序 API
```java
Arrays.sort(intArr);                       // 双轴快排
Arrays.sort(IntegerArr);                   // TimSort（归并+插入，稳定）
Arrays.sort(arr, (a,b) -> a-b);            // 自定义
Collections.sort(list);                    // TimSort
list.sort((a,b) -> a.compareTo(b));
```
**快排 vs TimSort**：基本类型用双轴快排（快但不稳定）；对象用 TimSort（稳定）。

## 5.6 Top K 问题（高频）🔴
- **小根堆（大小 K）**：O(n log k)，适合 K 小，见数据结构篇堆。
- **快速选择（quickselect）**：O(n) 平均，基于 partition，只递归一侧。LC 215 第 K 大。
```java
public int findKthLargest(int[] nums, int k) {
    int target = nums.length - k;   // 升序中第 n-k 个就是第 K 大
    int l = 0, r = nums.length - 1;
    while (l < r) {
        int p = partition(nums, l, r);  // 同快排 partition
        if (p == target) return nums[p];
        else if (p < target) l = p + 1;
        else r = p - 1;
    }
    return nums[l];
}
```

# 六、常考模板速查 🔴

| 套路 | 适用 | 复杂度 |
|------|------|--------|
| 对撞双指针 | 有序数组两数和 | O(n) |
| 快慢双指针 | 原地修改/链表 | O(n) |
| 滑动窗口 | 连续子数组/子串 | O(n) |
| 二分查找 | 有序/答案边界 | O(log n) |

| 快排/归并 | 排序 | O(n log n) |
| 小根堆 TopK | 前 K 个 | O(n log k) |
