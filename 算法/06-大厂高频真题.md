## 字节风格 Hard 举例
- **K 个一组翻转链表**（LC 25）：
```java
public ListNode reverseKGroup(ListNode head, int k) {
    ListNode dummy = new ListNode(-1); dummy.next = head;
    ListNode prev = dummy;
    while (true) {
        // 检查剩余是否有 k 个
        ListNode tail = prev;
        for (int i = 0; i < k; i++) {
            tail = tail.next;
            if (tail == null) return dummy.next;
        }
        ListNode next = tail.next;
        // 翻转 [prev.next, tail]
        ListNode[] reversed = reverse(prev.next, tail);
        prev.next = reversed[0];
        reversed[1].next = next;
        prev = reversed[1];
    }
}
```

# 九、面试前冲刺建议 🔴

**面试前 1 周**：
1. 用 **Codetop**（https://codetop.cc/）查目标公司近 3 月高频题，定向刷 20 道。
2. **手撕题默写 3 遍**：LRU、生产消费、单例（5 分钟内写出）。
3. **错题三刷**：把之前做错的重新做一遍。
4. **模拟限时**：每题限时 25 分钟，白板写。
5. **复习模板**：滑动窗口、二分、回溯、DP 的模板代码。

**面试当天**：
- 提前 1 小时做 1 道 Easy 热身（找手感）。
- 心态：不会的题说思路，别卡死。
