# 一、数组（Array）

## 1.1 概念
- **连续内存**存储相同类型元素，**下标从 0 开始**。
- **随机访问 O(1)**（下标计算地址），**插入/删除 O(n)**（要搬移元素）。
- Java 中 `int[]`、`ArrayList`（封装动态数组）。

```
下标:  0   1   2   3   4
值:   [10][20][30][40][50]
内存: 连续
```

## 1.2 操作与复杂度
| 操作 | 复杂度 |
|------|--------|
| 按下标访问 `arr[i]` | O(1) |
| 头部插入 | O(n) |
| 尾部插入 | O(1)（动态数组均摊） |
| 中间插入/删除 | O(n) |
| 查找（无序） | O(n) |
| 查找（有序，二分） | O(log n) |

## 1.3 动态数组（ArrayList）原理
- 初始容量（默认 10），不够时**扩容 1.5 倍**（`Arrays.copyOf` 复制）。
- 均摊 O(1) 尾插（n 次 append 触发一次扩容，总搬移 O(n)，平均每次 O(1)）。

## 1.4 高频题型 🔴
- **双指针**（对撞、快慢）→ 见算法/02
- **滑动窗口** → 见算法/02
- **前缀和** → 见算法/02
- **二分查找** → 见算法/02
- **矩阵遍历**（DFS/BFS、螺旋矩阵）

## 1.5 常考题（Java）
**反转数组**（双指针）：
```java
public void reverse(int[] nums) {
    int l = 0, r = nums.length - 1;
    while (l < r) {
        int t = nums[l]; nums[l] = nums[r]; nums[r] = t;
        l++; r--;
    }
}
```

**移动零**（LeetCode 283，快慢指针）：
```java
// 把所有 0 移到末尾，保持非零元素顺序
public void moveZeroes(int[] nums) {
    int slow = 0;  // 指向下一个非零应放的位置
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            int t = nums[slow]; nums[slow] = nums[fast]; nums[fast] = t;
            slow++;
        }
    }
}
```

# 二、链表（Linked List）

## 2.1 概念
- 节点通过**指针**连接，内存不连续。
- **插入/删除 O(1)**（改指针），**访问 O(n)**（从头遍历）。
- 类型：单链表、双链表、循环链表。

```
单链表：
head → [val|next] → [val|next] → [val|next] → null

双链表：
null ← [prev|val|next] ⇄ [prev|val|next] ⇄ [prev|val|next] → null
```

## 2.2 Java 定义
```java
class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}
```

## 2.3 复杂度
| 操作 | 单链表 | 双链表 |
|------|--------|--------|
| 查找 | O(n) | O(n) |
| 头插 | O(1) | O(1) |
| 尾插 | O(n)（无尾指针） | O(1)（有尾指针） |
| 删除给定节点 | O(n)（要先找前驱） | O(1)（有 prev 指针） |

## 2.4 🔴 核心技巧：虚拟头节点（Dummy Head）
链表题**90% 要用 dummy**，统一处理头节点被删的情况：
```java
ListNode dummy = new ListNode(-1);
dummy.next = head;
// ... 操作 ...
return dummy.next;
```

## 2.5 🔴 快慢指针（核心技巧）
- **找中点**：快指针走 2 步，慢指针走 1 步，快到尾慢在中点。
- **判断环**：快慢相遇有环。
- **找倒数第 k 个**：快先走 k 步，再一起走。

## 2.6 常考题（Java）

**反转链表**（LeetCode 206，必背）：
```java
// 迭代：逐个翻转指针
public ListNode reverse(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;  // 暂存
        curr.next = prev;           // 翻转
        prev = curr;                // 前移
        curr = next;
    }
    return prev;
}

// 递归
public ListNode reverseRec(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode newHead = reverseRec(head.next);
    head.next.next = head;  // head.next 是反转后的尾，它的 next 指回 head
    head.next = null;
    return newHead;
}
```

**环形链表**（LeetCode 141）+ 找环入口（142）：
```java
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;        // 慢 1 步
        fast = fast.next.next;   // 快 2 步
        if (slow == fast) return true;  // 相遇有环
    }
    return false;
}
```

**合并两个有序链表**（LeetCode 21）：
```java
public ListNode merge(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(-1), cur = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { cur.next = l1; l1 = l1.next; }
        else { cur.next = l2; l2 = l2.next; }
        cur = cur.next;
    }
    cur.next = (l1 != null) ? l1 : l2;  // 接剩下的
    return dummy.next;
}
```

**链表中倒数第 k 个节点**（快慢指针）：
```java
public ListNode getKthFromEnd(ListNode head, int k) {
    ListNode fast = head, slow = head;
    for (int i = 0; i < k; i++) fast = fast.next;  // 快先走 k 步
    while (fast != null) { fast = fast.next; slow = slow.next; }
    return slow;
}
```

# 三、栈（Stack）

## 3.1 概念
- **后进先出 LIFO**（Last In First Out）。
- 操作：push / pop / peek / isEmpty，都 O(1)。

```
入栈: push(1) push(2) push(3)
栈:  [3]  ← 顶
     [2]
     [1]  ← 底
出栈: pop() → 3
```

## 3.2 Java 实现 🔴
**不要用 `java.util.Stack`**（继承 Vector，方法加了 synchronized，性能差）。用 **`ArrayDeque`**：
```java
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);     // 入栈
stack.pop();       // 出栈
stack.peek();      // 查看栈顶
stack.isEmpty();
```

## 3.3 高频题型 🔴
- **括号匹配**（有效括号）
- **表达式求值**（逆波兰、中缀转后缀）
- **单调栈**（下一个更大元素、柱状图最大矩形）→ 见算法/03
- **DFS 的迭代写法**（用栈模拟递归）
- **最小栈**（O(1) 获取最小值）

## 3.4 常考题（Java）

**有效的括号**（LeetCode 20，必背）：
```java
public boolean isValid(String s) {
    Map<Character,Character> map = Map.of(')','(', '}','{', ']','[');
    Deque<Character> st = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(' || c == '{' || c == '[') st.push(c);
        else {
            if (st.isEmpty() || st.pop() != map.get(c)) return false;
        }
    }
    return st.isEmpty();
}
```

**最小栈**（LeetCode 155，辅助栈）：
```java
class MinStack {
    Deque<Integer> stack, minStack;
    public MinStack() { stack = new ArrayDeque<>(); minStack = new ArrayDeque<>(); }
    public void push(int x) {
        stack.push(x);
        if (minStack.isEmpty() || x <= minStack.peek()) minStack.push(x);
    }
    public void pop() {
        int x = stack.pop();
        if (x == minStack.peek()) minStack.pop();
    }
    public int top() { return stack.peek(); }
    public int getMin() { return minStack.peek(); }
}
```

# 四、队列（Queue）

## 4.1 概念
- **先进先出 FIFO**。
- 操作：offer / poll / peek，O(1)。

## 4.2 Java 实现
```java
Queue<Integer> queue = new LinkedList<>();   // 链表实现
Queue<Integer> q = new ArrayDeque<>();       // 数组实现（推荐）
```

## 4.3 双端队列（Deque）🔴
两端都能进出，**当栈、当队列、当单调队列都行**，超级重要：
```java
Deque<Integer> deque = new ArrayDeque<>();
deque.offerFirst(x); deque.offerLast(x);
deque.pollFirst(); deque.pollLast();
deque.peekFirst(); deque.peekLast();
```

## 4.4 高频题型
- **BFS 层序遍历**（树、图、最短路径）
- **单调队列**（滑动窗口最大值）
- **设计循环队列**（手撕）

## 4.5 常考题：用栈实现队列（LeetCode 232）
```java
class MyQueue {
    Deque<Integer> in = new ArrayDeque<>(), out = new ArrayDeque<>();
    public void push(int x) { in.push(x); }
    public int pop() { peek(); return out.pop(); }
    public int peek() {
        if (out.isEmpty()) while (!in.isEmpty()) out.push(in.pop());  // 倒
        return out.peek();
    }
    public boolean empty() { return in.isEmpty() && out.isEmpty(); }
}
```

# 五、堆 / 优先队列（Heap）

## 5.1 概念
- **完全二叉树**，父节点 ≥/≤ 子节点（大根堆/小根堆）。
- 用**数组**实现：节点 i 的父 `(i-1)/2`，左子 `2i+1`，右子 `2i+2`。
- **堆顶**是最大/最小值，O(1)；插入/删除 O(log n)。

```
大根堆：
        9
       / \
      7   8
     /\   /
    3 5  6

数组：[9,7,8,3,5,6]
```

## 5.2 Java 用法 🔴
```java
PriorityQueue<Integer> minHeap = new PriorityQueue<>();                          // 小根堆（默认）
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder()); // 大根堆
// 自定义比较（按某字段）
PriorityQueue<int[]> pq = new PriorityQueue<>((a,b) -> a[0]-b[0]);  // 按 a[0] 升序
pq.offer(x); pq.poll(); pq.peek();
```

**注意溢出** 🔴：`(a,b) -> a-b` 可能溢出（a 很大 b 很负），用 `Integer.compare(a,b)` 或 `a[0]-b[0]` 时小心。

## 5.3 高频题型 🔴
- **Top K 问题**（前 K 个最大/最小、第 K 大）
- **合并 K 个有序链表**
- **数据流中位数**（大根堆+小根堆）
- **任务调度**

## 5.4 常考题：前 K 个高频元素（LeetCode 347）
```java
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer,Integer> freq = new HashMap<>();
    for (int n : nums) freq.merge(n, 1, Integer::sum);
    // 小根堆，按频率，堆大小保持 k
    PriorityQueue<Integer> pq = new PriorityQueue<>((a,b) -> freq.get(a)-freq.get(b));
    for (int key : freq.keySet()) {
        pq.offer(key);
        if (pq.size() > k) pq.poll();  // 超过 k 弹出最小的
    }
    int[] res = new int[k];
    for (int i = 0; i < k; i++) res[i] = pq.poll();
    return res;
}
```

**Top K 解法对比** 🔴：
| 方法 | 时间 | 适用 |
|------|------|------|
| 排序后取前 K | O(n log n) | 简单 |
| 小根堆（大小 K） | O(n log k) | **K 远小于 n（推荐）** |
| 快速选择（quickselect） | O(n) 平均 | 需要手写，面试加分 |

# 六、二叉树（Binary Tree）

## 6.1 概念
- 每个节点最多两个子节点。
- **满二叉树**：每层都满；**完全二叉树**：除最后层都满，最后一层左对齐。
- **二叉搜索树 BST**：左 < 根 < 右，中序遍历是有序的。

```
        1
       / \
      2   3
     / \   \
    4   5   6
```

## 6.2 Java 定义
```java
class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int x) { val = x; }
}
```

## 6.3 🔴 三种遍历（必背）

```
前序 Preorder:  根 → 左 → 右    [1,2,4,5,3,6]
中序 Inorder:   左 → 根 → 右    [4,2,5,1,3,6]
后序 Postorder: 左 → 右 → 根    [4,5,2,6,3,1]
层序 Level:     按层从左到右    [1,2,3,4,5,6]
```

**递归遍历模板**（万能）：
```java
// 前序
void preorder(TreeNode root) {
    if (root == null) return;
    //visit(root);       // 前序位置
    preorder(root.left);
    //visit(root);       // 中序位置
    preorder(root.right);
    //visit(root);       // 后序位置
}
```

**中序的迭代写法**（用栈，常考）：
```java
public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> res = new ArrayList<>();
    Deque<TreeNode> st = new ArrayDeque<>();
    TreeNode cur = root;
    while (cur != null || !st.isEmpty()) {
        while (cur != null) { st.push(cur); cur = cur.left; }  // 一路向左压栈
        cur = st.pop();
        res.add(cur.val);
        cur = cur.right;
    }
    return res;
}
```

## 6.4 层序遍历（BFS，必背）🔴
```java
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new LinkedList<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int size = q.size();                 // 当前层节点数
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {     // 一次处理一层
            TreeNode node = q.poll();
            level.add(node.val);
            if (node.left != null) q.offer(node.left);
            if (node.right != null) q.offer(node.right);
        }
        res.add(level);
    }
    return res;
}
```

## 6.5 🔴 二叉树题的核心心法：递归思维
二叉树 90% 的题用递归。**核心**：想清楚**当前节点该做什么**，剩下的交给递归框架。

**三种常见思路**：
1. **能不能把问题拆成左右子树的子问题？**（后序，要左右的结果汇总）
2. **遍历一遍树，记录答案？**（前序，遍历思路）
3. **BST 用中序（有序性）**。

## 6.6 常考题

**最大深度**（LeetCode 104，后序）：
```java
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}
```

**翻转二叉树**（LeetCode 226）：
```java
public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    TreeNode t = root.left; root.left = root.right; root.right = t;
    invertTree(root.left); invertTree(root.right);
    return root;
}
```

**最近公共祖先**（LeetCode 236，经典）：
```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left == null) return right;
    if (right == null) return left;
    return root;  // 左右都非空，root 就是 LCA
}
```

**验证二叉搜索树**（LeetCode 98，中序递增）：
```java
long prev = Long.MIN_VALUE;
public boolean isValidBST(TreeNode root) {
    if (root == null) return true;
    if (!isValidBST(root.left)) return false;
    if (root.val <= prev) return false;  // 中序必须递增
    prev = root.val;
    return isValidBST(root.right);
}
```

# 七、哈希表（Hash Table）

## 7.1 概念
- 通过 **hash 函数**把 key 映射到数组下标，实现 O(1) 查找/插入/删除。
- 冲突解决：**链地址法**（拉链）、开放地址法。

```
buckets[]
[0] → null
[1] → (k1,v1) → (k5,v5)   链表
[2] → null
[3] → (k3,v3)
```

## 7.2 Java 用法
```java
Map<String, Integer> map = new HashMap<>();
map.put("a", 1);
map.get("a");                  // 1
map.getOrDefault("b", 0);      // 0（不存在返回默认）
map.containsKey("a");          // true
map.putIfAbsent("a", 2);       // 已存在不覆盖
map.merge("a", 1, Integer::sum); // 计数利器：a 的值 +1
```

## 7.3 高频题型 🔴
- **两数之和**（最经典）
- **计数**（出现次数、频率）
- **去重**（Set）
- **前缀和 + 哈希**（子数组和等于 K）
- **缓存/查表**

## 7.4 常考题

**两数之和**（LeetCode 1，必背）：
```java
public int[] twoSum(int[] nums, int target) {
    Map<Integer,Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int need = target - nums[i];
        if (map.containsKey(need)) return new int[]{map.get(need), i};
        map.put(nums[i], i);
    }
    return new int[]{};
}
```

**只出现一次的数字**（LeetCode 136，异或）：
```java
// 异或：相同为 0，a^a=0, a^0=a
public int singleNumber(int[] nums) {
    int x = 0;
    for (int n : nums) x ^= n;
    return x;
}
```

# 八、字符串（String）

## 8.1 Java 字符串要点 🔴

- `charAt(i)`、`substring(b,e)`、`toCharArray()`、`equals()`（别用 ==）。

## 8.2 高频题型
- 反转字符串/单词
- 回文判断
- 字符串匹配（KMP、Rabin-Karp）
- 最长公共前缀
- 字符计数（异位词、字母重排）

## 8.3 常考题

**反转字符串**（LeetCode 344）：
```java
public void reverseString(char[] s) {
    int l = 0, r = s.length - 1;
    while (l < r) {
        char t = s[l]; s[l] = s[r]; s[r] = t; l++; r--;
    }
}
```

**验证回文**（LeetCode 125）：
```java
public boolean isPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) {
        while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
        while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
        if (Character.toLowerCase(s.charAt(l)) != Character.toLowerCase(s.charAt(r))) return false;
        l++; r--;
    }
    return true;
}
```

**有效的字母异位词**（LeetCode 242，计数）：
```java
public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] cnt = new int[26];   // 假设小写字母
    for (char c : s.toCharArray()) cnt[c-'a']++;
    for (char c : t.toCharArray()) if (--cnt[c-'a'] < 0) return false;
    return true;
}
```

# 九、数据结构选型速查表 🔴

| 需求 | 选什么 |
|------|--------|
| 按下标快速访问 | 数组 / ArrayList |

| 层次遍历/最短步数 | 队列 BFS |
